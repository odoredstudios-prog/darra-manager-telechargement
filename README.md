# DARRA MANAGER — Téléchargements

Téléchargements officiels de **DARRA MANAGER**, logiciel de gestion scolaire.

👉 **Page de téléchargement : https://ecole-manager.onrender.com/telecharger**

| Application | Pour qui | Lien direct (dernière version) |
|---|---|---|
| Logiciel Windows | Direction et administration des établissements (Windows 10 / 11) | https://ecole-manager.onrender.com/telecharger/windows |
| Application Android | Parents d'élèves | https://ecole-manager.onrender.com/telecharger/android |

Toutes les versions sont dans l'onglet **Releases** de cette page.

## Installation du logiciel Windows

1. Téléchargez `DARRA-MANAGER-Setup-x.y.z.exe` et ouvrez-le.
2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires** puis **Exécuter quand même**.
3. Pour créer le compte de l'établissement, munissez-vous de la **clé d'activation** remise par DARRA MANAGER.

## Installation de l'application Android

1. Téléchargez `DARRA-MANAGER-x.y.z.apk` depuis le téléphone et ouvrez-le.
2. Si Android le demande, autorisez l'installation depuis votre navigateur.
3. Connectez-vous avec les identifiants remis par l'établissement.
